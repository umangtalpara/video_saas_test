### DEC-001: `.ai/` is canonical; tool folders are generated (2026-11-13)

- **Status**: Accepted
- **Decision**: `.ai/` is the only place to edit agents, skills, workflows and context. `.claude/`, `.cursor/` and `.agents/` are generated by `node .ai/scripts/sync-adapters.js` (verify with `--check`). Workflows are exposed as skills named `factory-<workflow>`. The Super Agent is the main session (Claude Code subagents cannot spawn subagents), so it is not generated as a subagent.
- **Why**: Removes drift and thin stubs; each tool gets the format it actually loads (Claude `SKILL.md`/agents, Cursor `.mdc`/commands, Antigravity `trigger` rules + `.agents/`).

### DEC-002: Single machine-readable state (2026-11-13)

- **Status**: Accepted
- **Decision**: `.ai/memory/state.json` is the single source of truth; all status markdown is generated by `status-manager.js`. Task retries are capped at 3, then BLOCKED with an auto-created blocker.

### DEC-003: Stack pins and upgrade path (2026-11-13)

- **Status**: Accepted
- **Decision**: Stay on NestJS 11 / Next.js 14 / React 18 / Tailwind 3 / Prisma 5, with Nest-ecosystem packages matched to Nest 11 (swagger 11, config 4, schedule 6, cache-manager 3, throttler 6) and `shadcn@2.3.0` for Tailwind v3. Newer majors (Nest 12, Next 16, React 19, Tailwind 4, Prisma 7) are an explicit future migration, see `.ai/context/tech-stack.md`.
- **Also**: JWT defaults to HS256 with a >=32-char secret (RS256 optional); `exactOptionalPropertyTypes` is off; tests live inside each codebase.
